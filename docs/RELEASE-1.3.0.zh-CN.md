# 浏览器控制 1.3.0

本次更新加入逐字输入和可选的页面脚本工具，并恢复了浏览器快照的完整可交互元素列表。

## 相比 1.2.0 的改动

- **逐字输入。** 新增 `browser_type_text`，可在文本框、多行文本框和可编辑区域逐字输入，支持中文、emoji 和多行文本。输入时目标标签页须位于前台，工具不会自动提交表单。原有快速填入仍可使用。
- **输入中断时报告进度。** 焦点变化、连接断开或输入暂停时，工具会报告已输入的部分，不会自动重放整段文本，也不会把输入内容写入日志。
- **可选的页面脚本。** 新增 `browser_eval`，可在用户已授权的页面执行 JavaScript。使用前需要在扩展设置中单独启用“页面脚本执行”。仅在有权自动化的页面上使用。
- **快照返回更多可交互元素。** 移除了只返回前 5 个可交互元素的限制。大型网页的工具返回内容可能随之增多。

## 从 1.2.0 升级

请整体替换便携程序目录。若使用未打包扩展，请从更新后的目录重新加载扩展。保留原数据目录可以沿用已有配对和设置。

逐字输入和页面脚本需要浏览器调试权限，更新扩展时浏览器可能要求接受新权限。两个功能各自在扩展设置中启用。接入 Codex、DSH 或其他 MCP 客户端前，请先在控制面板启动本地服务。
