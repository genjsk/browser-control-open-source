# 浏览器控制 1.4.0

1.4.0 支持把不同的 AI 接入实例绑定到不同的浏览器，改进了大型网页的读取和填写核验，并新增 Windows 安装器，支持全新安装和原地升级。

## 相比 1.3.0 的改动

- **一个服务连接多个浏览器。** 多个浏览器或独立浏览器配置可以使用同一配对码。在控制面板的「AI 接入情况」中，为 Codex、DSH 等接入实例选择对应的浏览器。指定浏览器离线时，该实例会暂停调用，直到浏览器重新连接或更改分配。
- **按需读取网页。** `browser_snapshot` 默认读取主页面前 1,500 个字符和首批 20 个控件。可以搜索控件标签、继续翻页，或按需读取同源子框架。`browser_inspect` 可查看单个控件的值、勾选状态和下拉选项。
- **核对填写结果。** 填入操作会立即返回值核验结果。可以用 `browser_wait` 等待指定页面或框架出现保存、提交等确认提示。工具回执也精简了，仍会报告端口、配对和连接检查结果。

## Windows 安装器

- 安装器会列出检测到的旧版及完整路径。可选中其中一份原地升级，也可安装到新位置。新位置已有内容时，安装器会在同级创建带编号的目录，并显示实际安装路径。
- 原地升级保留现有数据位置和程序目录中的 `.local`。安装器会显示端口检查、解压和文件替换进度。若 Windows 拒绝创建暂存目录，可通过 UAC 以管理员身份重新打开安装器，继续使用已选的旧版和目标路径。
- 安装完成后会检查 Codex 原生插件，以及可读取的 DSH Desktop 和 DSH Web 配置中的插件版本。可从安装器更新 Codex 原生插件，或生成新版 DSH 插件目录供客户端加载。

## 下载

| 文件 | 用途 |
| --- | --- |
| `browser-control-1.4.0-win32-x64-setup.exe` | Windows x64 安装包，支持全新安装和升级 |
| `browser-control-1.4.0-win32-x64.zip` | Windows x64 便携包，解压完整目录后运行 `BrowserControl.exe` |

Windows 安装包和便携包内置运行环境，安装或解压时无需另行下载 Python、Node.js 或 npm。

## 从旧版升级

1. 在旧版控制面板点击「断开」，关闭旧版控制面板和正在使用浏览器控制的 AI 客户端。
2. 打开 1.4.0 安装器，选择「升级已有版本」，核对程序路径后确认。列表里找不到旧版时，可以用「添加旧版目录」手动选取。
3. 打开新版控制面板并点击「连接」。在 Chrome 或 Edge 的扩展管理页重新加载扩展。若程序路径变了，从新程序目录加载 `extension` 文件夹。
4. 按安装器提示更新所需的 AI 插件，然后重启对应的客户端。
